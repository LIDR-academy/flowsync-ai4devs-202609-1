## Overview

FlowSync is a team task-management practice project (AI4Devs course). Two independent packages, each with its own `package.json` and `npm install`:

- `backend/` — AdonisJS 7 API (TypeScript, ESM, Lucid ORM, SQLite via better-sqlite3, VineJS validation, Japa tests). Port 3333.
- `frontend/` — React 19 + Vite 8 + TypeScript. Port 5173. Currently the bare Vite template (`src/App.tsx` only); no router, API client or auth yet.

`README.md` (in Spanish) also contains the course exercise (harness comparison, PR delivery rules). `prompts.md` at the root is a deliverable template for prompts used; don't overwrite it casually.

## Commands

Backend (run from `backend/`):

```bash
cp .env.example .env && node ace generate:key   # first-time setup (APP_KEY is empty by default)
node ace migration:run                          # also regenerates database/schema.ts
npm run dev                                     # node ace serve --hmr
npm test                                        # node ace test
node ace test --files tests/<path>.spec.ts      # single file (also: --tests "<title>")
npm run lint | npm run typecheck | npm run format
npm run build
```

Frontend (run from `frontend/`): `npm run dev`, `npm run build` (runs `tsc -b` then vite), `npm run lint` (oxlint). No test runner is configured.

## Backend architecture

- **Routes** (`start/routes.ts`): everything is under `/api/v1`. `auth/signup` and `auth/login` are public; `account/profile` and `account/logout` sit behind `middleware.auth()`. Controllers are referenced via the generated `controllers` object (`#generated/controllers`) rather than direct imports.
- **Auth**: token-based. `config/auth.ts` defines `api` (access tokens, the default) and `web` (session) guards; the controllers use the `api` guard, issuing tokens with `User.accessTokens.create` on login and deleting them on logout.
- **Responses**: controllers return `serialize({...})` with transformers (`app/transformers/`) instead of serializing models directly. `force_json_response_middleware` forces JSON responses.
- **Validation**: VineJS validators in `app/validators/`, used via `request.validateUsing(...)`.
- **Imports**: use the `#controllers/*`, `#models/*`, `#validators/*`, etc. subpath aliases defined in `backend/package.json` (`imports`), not relative paths.
- **Generated files — don't edit by hand**:
  - `database/schema.ts` (Lucid schema classes, regenerated by `migration:run`); models in `app/models/` extend these generated classes, so schema changes go in a migration, then run it.
  - `.adonisjs/` (typed controllers/routes/client registry, regenerated by `node ace` / dev server). It is tracked in git, so it shows up as modified after running the app; the `backend` package exports `./data` and `./registry` from it for type-safe frontend API use (Tuyau).
- **CORS**: open in dev (`origin: true`), empty allow-list in production; set `CORS_ORIGIN` in `.env` for other origins.
- **Tests**: `tests/bootstrap.ts` configures Japa (api-client, session and auth plugins, typed route registry); there are no spec files yet.
